# Docker $250 Agent Challenge — 2:00 demo video script (DRAFT)

Narration timed to swarm.py's existing shot list. ~300 words at ~150 wpm.
Voice rule: Maya (avocado_v2:MAI_01) for lab voiceovers.

## 0:00–0:15 — boot
"This is the agent that spends money without holding keys. It makes real paid
API calls — twenty-five cents to compress, ten to decompress — settled in
stablecoin. Key inventory: zero. No wallet keys. No API tokens. The agent never
touches money it can't account for."

## 0:15–0:45 — the crew
"Every call is authorized by a signed Warrant — a spend mandate — and the agent
authenticates with a verified Agent-Rider identity. Here, the operator issues a
one-dollar warrant, delegates forty cents each to a scout and a worker, and
they run concurrently. Every cent lands on the ledger."

## 0:45–1:00 — depth
"Authority attenuates down the chain: one hundred cents, to forty, to fifteen.
The sub-scout inherits only what was delegated. Budgets strictly shrink — a
sub-agent can never spend more than its parent gave it."

## 1:00–1:20 — denial #1
"The sub-scout tries a twenty-five cent compress on a fifteen cent cap. Denied:
OVER_BUDGET. The denial is the product. A polite 'no' on camera is worth more
than a thousand allowed calls."

## 1:20–1:40 — denial #2
"This warrant lives for four seconds. Allowed on entry… expired on exit. Time
is a permission too, and it dies on camera."

## 1:40–1:50 — denial #3
"A forged identity never even reaches the spend logic. Identity first, money
second, deny by default."

## 1:50–2:00 — finale
"The budget tree: every cap, every cent, accounted for. The full build cost
three dollars fifty in cloud credit out of two hundred fifty. Identity is
verified, spend is bounded, and the agent never held a single key."
